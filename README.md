# Turbo Clothes

Responsive luxury men's clothing concept. Vanilla HTML, CSS and JavaScript; no dependencies.

## Preview
Run `npm run dev` and open http://localhost:3000.

## Vercel
Import TurboTwitch0/TurboClothes. The included vercel.json builds with npm run build and serves dist. No environment variables are required.

## Netlify
Import the same repository. netlify.toml sets the build command and publish directory automatically.

## Content and launch
Sample products, prices, and Unsplash imagery are placeholders. Replace the image URLs and product data in index.html with your own clothing images and catalog. Cart, sizes, category filtering, and local persistence work. Real payments, inventory, shipping, tax, and orders require a commerce backend before accepting purchases. No customer payment information is collected.

The source is ready for hosting; repository access does not automatically connect a Vercel or Netlify account.
